# G49 鼠标电量监控

一个 Windows 后台小程序：**定时读 Redragon G49 鼠标的剩余电量，电量低时用 Windows 系统通知提醒你**。
有中文控制界面，开机可以自动启动，点关闭后窗口消失、后台继续跑，**全程不碰托盘**。

---

## 怎么用

**启动**：双击 `dist\G49BatteryMonitor.exe`（不是 src 目录里的东西，就认这个）。

**看电量**：窗口里大字显示百分比、电压、当前连接方式（有线 / 2.4G）、是否在充电、最后更新时间。

**关闭窗口**：点右上角 × **不会退出程序**，只是把窗口藏起来，后台继续监控。
想再看的时候，**再双击一次那个 exe 就行**（不会启动第二个程序，只是把原来的窗口叫回来）。

**真正退出**：只能在窗口里点「退出」按钮，会问你一次确认。退出后监控停止，直到下次开机或你再运行。

**立即刷新**：窗口里的「立即刷新」按钮，不用等下一个周期。

---

## 提醒长什么样

用的是**真正的 Windows 系统通知**：

- 右下角弹横幅，**会留在「通知中心」里**（Win + N 打开就能看到历史），不会像气泡那样一闪就没；
- 点通知可以把程序窗口叫出来；
- 提示音可以单独开关（默认开）；
- 如果系统通知因为某些策略发不出去，程序会自动改用自绘的右下角小卡片兜底，**不会出现"该提醒却没提醒"**。

**因为它压根不用托盘，所以托盘区永远不会有这个程序的任何图标**——不管是运行中还是退出后。

## 开机自动启动

窗口里有个「开机自动启动」勾选框，**默认是不勾的**——程序不会自己往注册表里写东西，得你自己勾。

勾上之后：开机时会**静默启动**（没有任何窗口弹出来，直接在后台开始监控）。
它会写一条当前用户的启动项（`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 里的 `G49BatteryMonitor`），**不需要管理员权限**。

如果你把 `dist` 文件夹搬到了别的地方，程序每次启动会自己把那条启动项修正成新路径，不用手动改。

取消勾选 = 删掉那条启动项。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 查询间隔 | 5 分钟 | 多久问一次鼠标电量。可改 30 秒 / 1 分钟 / 5 分钟 / 15 分钟 |
| 预警阈值 | ≤20% / ≤10% / ≤5% | 三档提醒，每档只提醒一次，插线充电后自动重置 |
| 低电量提示音 | 开 | 不要声音就取消勾选 |
| 开机自动启动 | 关 | 见上一节 |

程序还会自动做这几件事，不用你管：

- **有线连接时改成 1 分钟查一次**（有线不耗鼠标电池，查勤一点没关系）；
- **查不到设备时每 15 秒重试一次**——所以拔线、插线、鼠标从休眠里醒过来，都能很快反映到界面上，不会傻等 5 分钟；
- **插拔瞬间重新选择接口**：插上线立刻切到"有线"，拔了线立刻切回"2.4G"；
- **电量充满**（≥99% 且正在充电）提示一次"可以拔线了"。

每次改设置都会写进日志，比如 `设置变更：查询间隔改为 900 秒`——以后再出现"间隔怎么变了"，翻日志就有答案。

## 文件都在哪

```
G49MouseMonitor\
  dist\                    ← 程序本体，整个文件夹拷走就能用
    G49BatteryMonitor.exe
    config.json            ← 你的设置
    logs\                  ← 运行日志（按天分文件，单个超 1MB 自动换新）
    selftest.txt           ← 跑 --selftest 时生成
    notify-test.txt        ← 跑 --test-notify 时生成
  src\                     ← 源代码
  .nuget\                  ← 微软官方 Windows API 投影包的缓存（约 75MB）
  nuget.config             ← 把上面这个缓存目录钉在项目里，不让它落到 C 盘
  docs\                    ← 实测证据日志 + 界面截图
```

**关于"不占 C 盘"**：程序本身只有一个 NuGet 依赖——微软官方的 Windows API 投影包（发系统通知必须用它）。
它的缓存被 `nuget.config` 固定到了项目里的 `.nuget` 文件夹，**C 盘的 NuGet 缓存是空的**（实测确认）。
代价是 `dist` 里会多一个约 24MB 的 `Microsoft.Windows.SDK.NET.dll`。

**注册表方面**：程序只会在你**自己勾选**开机自启时写一条启动项，别的一概不写。

## 不想要了怎么卸载

1. 打开窗口，取消勾选「开机自动启动」；
2. 点「退出」；
3. 删掉 `dist` 文件夹（`.nuget` 和 `src` 也可以一起删）。

完事，注册表和 C 盘都不会有残留。

## 已知限制（硬件决定的，不是程序偷懒）

1. **这款鼠标没有 Windows 标准的电池设备**，电量必须"主动发命令去问"才知道，所以：
   - 电量数字最多滞后一个查询周期（默认 5 分钟）；
   - **鼠标自己休眠 / 关机 / 接收器没插的时候，程序查不到数据，也就发不出预警**。界面会显示"未连接"，并保留一行灰色的"最后读数 40%（12:03）"；
   - 拔线之后，**鼠标自己需要几秒**重新和接收器建立无线连接，这几秒显示"未连接"是正常的。
2. **只能监控，不能控制**。程序只会发一条"查电量"的命令，不会改鼠标的任何设置。
3. 目前只支持 **Redragon G49（USB 厂商 ID 0x3554）**，支持 2.4G 接收器和有线两种接法，并会自动切换。
4. 程序**不干扰**你正常用鼠标，也不影响网页版控制器——多个程序可以同时读这个设备。

## 编译

需要 .NET 9 SDK（本机已装）。在 `src` 目录下：

```
dotnet publish -c Release -o ..\dist
```

首次编译会联网下载微软官方的 Windows API 投影包；缓存位置由项目根目录的 `nuget.config`
固定在 `.nuget` 文件夹里，**不会写进 C 盘**。
